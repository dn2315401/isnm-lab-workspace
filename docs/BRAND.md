# 지능형 연성 나노 소재 연구실 브랜드 적용

## 이름과 원본 로고

- 국문: 지능형 연성 나노 소재 연구실
- 영문: Intelligent Soft Nano Materials LAB
- 약칭: ISNM LAB
- 심벌 파일: `public/brand/isnm-symbol.png`

사용자가 제공한 심벌과 동일한 [공식 연구실 홈페이지](https://www.isnmlab.com/)의 원본 PNG를 사용했습니다. 로고를 다시 그리거나 모양·색을 수정하지 않았습니다. 파일은 투명 배경의 358×330 PNG이며 원본 비율을 유지하여 표시합니다.

원본 주소: https://static.wixstatic.com/media/9571c6_a7cec3766b0d47fe860b734b68aa7cf1~mv2.png

심벌은 사이드바, 홈 소개 영역, 하단 연구실 표시와 브라우저 아이콘에 사용합니다. 작은 화면에서는 심벌을 유지하고 긴 연구실 이름은 레이아웃에 맞게 정리합니다.

## 색상 선택

여러 원색을 같은 비중으로 사용하면 연구 데이터의 위계와 상태를 구분하기 어려워집니다. 로고의 파란 영문 글자를 중심색으로 삼고, 원 안의 세 색은 적은 면적으로 사용합니다.

| 역할 | 색상 |
| --- | --- |
| 주요 제목·연구실 이름 | 딥 네이비 `#103F74` |
| 주요 동작·선택 메뉴·링크 | 연구실 블루 `#155FB4` |
| 배경 | 차가운 연회색 `#F5F8FC` |
| 카드·입력창 | 흰색 `#FFFFFF` |
| 구분선 | `#DCE6F0` |
| 본문 | `#193651` |
| 보조 설명 | `#586F88` |
| 포인트 노랑 | `#F4D44C`, 옅은 배경 `#FFF8DA` |
| 포인트 분홍 | `#E95CA9`, 옅은 배경 `#FCECF4` |
| 포인트 초록 | `#70D36A`, 옅은 배경 `#EAF7EC` |

밝은 포인트색을 작은 글자에 바로 사용하지 않습니다. 노랑 배지 글자는 `#765B00`, 분홍은 `#91365F`, 초록은 `#2E7047`처럼 진한 색을 사용합니다. 오류는 구분 가능한 붉은 계열과 설명 문구를 유지합니다.

## 적용한 화면

사이드바 로고·연구실 이름, 선택 메뉴, 홈 배너, 프로젝트 카드와 진행률, 조성 표, 계산기 모달, 원료·올리고머 관리, 장비 예약과 달력, 데이터 검색·비교, 알림과 설정·하단 정보의 색상을 정리했습니다. 이전 글자 크기 개선과 연구 기능·데이터 구조는 유지합니다.

`src/LabLogo.tsx`는 이름·심벌 표시, `src/brand.css`는 공통 색상과 브랜드 배치를 관리합니다. 기존 CSS에 남아 있던 보라색과 매우 옅은 회청색 텍스트도 같은 계열로 정리했습니다.

## 검증

PNG 형식·원본 비율·투명도, 원본/배포 파일의 동일성, 주요 텍스트/배경 색상 쌍의 대비, CSS 파싱과 빌드를 확인합니다. 실제 브라우저 화면 검증은 현재 환경에 지원되는 브라우저 제어 도구가 없어 수행하지 못했습니다. 개별 표나 모든 상태의 WCAG 적합성을 보증하는 검증은 아닙니다.
