# RIGOL DP811A 추가 — 2026-11-24 v1

최신 수정: 사용자 요청에 따라 매뉴얼은 파일 업로드·원본 다운로드만 제공합니다. 텍스트 보기, 슬라이드 보기, PDF 미리보기와 새 업로드의 텍스트 추출은 제거했습니다. 기존 원본 파일·안전 안내·실험 기록은 유지합니다. 아래 초기 구현의 미리보기 설명은 이 수정으로 대체되었습니다.

## 장비와 예약

DC 전원공급장치 / DC Power Supply, RIGOL DP811A, 전기·전자 실험 장비. LCE 필름 전열·전기 구동 실험용 단일 채널 전원공급기로 Range 1 20 V/10 A, Range 2 40 V/5 A, 정격 200 W입니다. 위치·담당자·관리번호는 비워 두었으며 기존 장비 설정에서 입력할 수 있습니다.

기존 장비 카탈로그를 읽을 때 DP811A를 병합합니다. 동일 ID/모델이 있으면 기존 ID·운영 설정을 유지하며 중복 모델의 옛 ID도 예약 참조로 인식합니다. 다른 장비·기존 예약·점검 자료를 덮어쓰지 않습니다. 기본 운영 시간·예약 단위는 기존 공통 예약 방식을 적용하며 실제 운영 규정에 맞게 장비 설정에서 조정합니다.

일반 장비 달력과 홈 빠른 예약 모두 동일 reservationError를 사용합니다. 기존 시작·종료·시간 중복·점검·최대 시간·기간·예약자 소유권·수정 revision·취소 규칙에 DP811A의 선택 Range·예정 전압·전류 검증만 추가합니다. 입력한 값은 유한한 0 이상 숫자여야 하며 선택 Range 한도와 200 W를 초과할 수 없습니다. 전압/전류를 입력하면 Range 확인을 요구합니다.

기존 장비 예약 자체는 브라우저 localStorage 및 navigator.locks 기반이며 장비 관리자 화면은 기존 미리보기 설정입니다. 다른 브라우저 사이의 예약 중복을 막는 서버 예약 시스템으로 바뀐 것은 아닙니다. 사용자 요청대로 다른 장비의 저장·권한 방식을 전면 변경하지 않았습니다.

## 첨부 매뉴얼

`public/manuals/dc-supply-manual.pptx`는 첨부한 `DC supply manual.pptx`의 실제 원본(4,194,647 bytes)입니다. 테스트에서 SHA-256 일치를 검증했습니다. 실제 배포 자산으로 포함하며 다운로드 링크만 꾸며두지 않았습니다.

30장 슬라이드에서 추출한 텍스트를 `dc-supply-manual.json`에 보관하여 웹에서 읽을 수 있습니다. 텍스트 보기는 그림·배치·도식을 재현하는 슬라이드 렌더링이 아닙니다. 원본 내용은 PowerPoint에서 확인할 수 있습니다.

모든 장비의 상세·매뉴얼 화면에 PDF/PPT/PPTX 업로드(최대 8 MB)를 제공합니다. 파일 형식·실제 헤더·용량·구성원 승인을 검증합니다. 업로드 파일은 D1 문서/청크 테이블에 원본 바이트와 SHA-256으로 저장하며 저장 성공 후 조회된 목록만 표시합니다. PDF는 브라우저 미리보기·원본 다운로드, PPTX는 브라우저가 압축 해제를 지원하고 텍스트를 추출한 경우 텍스트 보기·원본 다운로드, 옛 PPT는 원본 다운로드 후 PowerPoint 열기를 제공합니다. 미리보기 불가를 파일 저장 성공처럼 표시하지 않습니다.

## 안전 안내

예약 입력·예약 상세·장비 매뉴얼에서 사용자 요청의 7가지 주의사항을 표시합니다. 출력 Range와 전압/전류, 전원·케이블, 출력 ON 상태 접촉 금지, 절연 보호구·젖은 손 금지, IR 카메라 온도 확인, 필름·에나멜선 국부 과열, 종료 후 OFF 확인입니다. 연구실 매뉴얼 슬라이드 30의 온도·에나멜 피복 경고도 출처와 함께 안내하며 특정 온도를 보편적 안전 보장으로 해석하지 않습니다. 상세 그림과 절차는 원본 슬라이드로 제공합니다.

## 실제 실험 기록과 파일

예약만으로 실제 실험을 자동 생성하지 않습니다. 실제 실험일·선택 예약 참조·프로젝트·샘플·분석 ID·Range·실제 전압/전류·인가 시간(s)·측정 온도·관찰/결과를 별도 공용 기록으로 저장합니다. 선택 파일은 저장된 실험 ID에만 연결합니다. 파일 업로드가 실패해도 저장된 실험과 실패한 첨부를 구분하고 재시도할 수 있습니다.

프로젝트·샘플은 현재 브라우저에 존재하는 원본을 선택하며, 다른 브라우저에 없는 원본이나 자유 입력한 분석 ID는 참조만 보관했다는 안내를 표시합니다. 작성한 실제 실험은 기존 측정 검색 자료에도 참조를 저장하여 프로젝트·샘플·분석 화면과 함께 찾을 수 있습니다. 실험 원본은 D1에, 검색용 참조는 기존 브라우저 저장소에 있습니다. 첨부는 PNG/JPEG/PDF/CSV/JSON/TXT를 지원합니다.
